# NTO Hogwarts — client releases

Este repositório **só hospeda os builds do client** (OTClient) do NTO Hogwarts. Não há código-fonte aqui.
O código fica no repositório privado `2hdsc/otclient`; os builds são publicados aqui por CI/script de release.

| Tag | Canal | Servidor no `init.lua` |
|---|---|---|
| `vX.Y.Z` | prod (release normal, "latest") | `ntohogwarts.servegame.com:7171` |
| `vX.Y.Z-staging` | staging (prerelease) | `staging-ntohogwarts.servegame.com:7271` |

Downloads pelo portal:
- Prod: https://shinobi-ntohogwarts.pages.dev/baixar
- Staging: https://staging-shinobi-ntohogwarts.pages.dev/baixar

Cada release traz `checksums.txt` (SHA-256) dos pacotes.
Não abra issues/PRs aqui; o repositório é só de distribuição.
